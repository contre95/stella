## Container image

Images are published to the GitHub Container Registry:

```bash
podman pull ghcr.io/contre95/stella:beta   # newest release
```

Every version is listed in [GitHub packages](https://github.com/contre95/stella/pkgs/container/stella).
There is deliberately no `latest` tag: pin a version, or track `beta`.

| Tag       | What it is                         |
| --------- | ---------------------------------- |
| `vX.Y.Z`  | An exact release, immutable        |
| `beta`    | Newest release, the tag to follow  |
| `nightly` | `main` as of 02:00 UTC             |

## Running

The web UI listens on port `8858`; the [MCP endpoint](mcp.md), when enabled, is served on
the same port at `/mcp`. The image ships `config.example.yaml` as `/app/config.yaml`, and
keeps its database and uploaded media under `/app/data`.

```bash
podman run -d \
  --name stella \
  -p 8858:8858 \
  -v /host/stella/data:/app/data \
  -v /host/stella/config.yaml:/app/config.yaml \
  ghcr.io/contre95/stella:beta
```

The config path can be changed with `STELLA_CONFIG_PATH`. See [Configuration](config.md)
for every setting.

## Building it yourself

```bash
IMAGE_TAG=stella podman build -t stella .
```

`IMAGE_TAG` is baked in as an env var and is what the UI shows as its version; it falls back
to `dev` when unset.

## Running from source

With [devenv](https://devenv.sh) + Nix:

```bash
devenv up   # Go + Tailwind CLI provided, CSS rebuilt on shell entry, runs the server
```

Otherwise:

```bash
go run ./src
```

`public/css/app.css` is generated by Tailwind from `styles/input.css`. A compiled copy is
committed so `go run` works out of the box; rebuild it if you change styles or template class
names (devenv does it for you).
